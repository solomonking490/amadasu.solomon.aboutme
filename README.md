# Osarumwense Solomon Amadasu — Portfolio Website

A responsive, static multi-page portfolio for GitHub Pages. The site uses plain HTML and CSS; there is no build step or package installation.

## Files
- `index.html` — home page and profile
- `cv.html` — professional experience, education, tools and certifications
- `work.html` — research, engineering work and ventures
- `achievements.html` — awards and milestones
- `contact.html` — contact details
- `style.css` — shared responsive styling
- `assets/osarumwense-amadasu.jpg` — profile portrait
- `.nojekyll` — disables GitHub Pages Jekyll processing

## Publish with GitHub Pages
1. Create a GitHub repository. For a user site, name it `YOUR-USERNAME.github.io`; for a project site, use any repository name.
2. Upload the **contents of this `site` folder** to the repository root (so `index.html` is at the root, not nested in another folder).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the Pages deployment to finish. GitHub will show the published address in Settings → Pages.
